📄 Importa da Excel

Singola riga

Uno o più file (Ctrl o Maiusc + clic), al massimo quante sono le etichette libere. Di ogni file viene letta solo la prima riga sotto le intestazioni; i file vengono inseriti in ordine alfabetico di nome.

Multiriga

Un solo file: un'etichetta per ogni riga dell'intervallo, al massimo quante sono le etichette libere. Numeri di riga come in Excel (la riga 1 contiene le intestazioni).
